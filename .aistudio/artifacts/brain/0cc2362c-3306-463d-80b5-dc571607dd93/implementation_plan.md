# แผนงาน: ระบบกำหนดค่าแรงและค่าบริการแบบกำหนดเอง (Custom Labor & Service Fees) พร้อมตรวจสอบ Code Error

ยกระดับระบบจัดการค่าแรงและค่าบริการของอู่ให้ยืดหยุ่นสูง สามารถกำหนดราคาเองได้ทั้งแบบยอดรวมและแยกรายการบริการย่อย พร้อมปุ่มลัดเลือกรายการประจำอู่ และแสดงผลในใบเสร็จ/ใบแจ้งหนี้เป็นบรรทัดเดียวพร้อมคำอธิบายสรุปงานบริการตามที่ผู้ใช้งานเลือก รวมถึงตรวจสอบแก้ไข Code Error ทั้งระบบให้พร้อมใช้งานจริง

---

## สรุปผลการสอบถามความต้องการ (Clarified Decisions)

> [!IMPORTANT]
> **สรุปตัวเลือกที่ผู้ใช้งานยืนยันแล้ว:**
> 1. **รูปแบบการจัดการค่าแรง/ค่าบริการ:** กำหนดได้ทั้งแบบยอดรวมและแยกรายการบริการย่อย พร้อมปุ่มลัดเลือกรายการประจำอู่ (Quick Presets)
> 2. **การแสดงผลในเอกสาร (ใบเสนอราคา / ใบเสร็จ / ใบแจ้งหนี้):** รวมเป็นบรรทัดเดียวพร้อมระบุคำอธิบายสรุปงานบริการ (Single Consolidated Line with Descriptive Summary)

---

## 1. ภาพรวมฟีเจอร์ & คุณค่าการใช้งาน (Overview & Value)

- **ความยืดหยุ่นหน้างาน:** เจ้าของอู่หรือหัวหน้าช่างสามารถปรับเปลี่ยนค่าแรงได้อิสระ ไม่ถูกล็อกราคา สามารถเลือกว่าจะกรอกยอดรวมก้อนเดียวพร้อมคำอธิบาย หรือจะแยกรายการย่อย (เช่น ค่าแรงเปลี่ยนถ่ายน้ำมันเครื่อง 200 + ค่าตรวจเช็คเบรก 300) แล้วให้ระบบรวมยอดให้อัตโนมัติ
- **ทำงานสะดวกรวดเร็ว:** มีปุ่มลัดคลิกเลือกรายการบริการมาตรฐานประจำอู่ (Standard Presets) ที่บันทึกไว้ในหน้าตั้งค่ามาใส่ในใบงานได้ทันทีเพียงคลิกเดียว
- **เอกสารดูเป็นมืออาชีพ:** เอกสารพิมพ์สำหรับลูกค้า (ใบเสร็จ/ใบแจ้งหนี้/ใบส่งมอบรถ) แสดงรายการค่าแรงเป็นบรรทัดเดียวที่สรุปชัดเจน เช่น *"ค่าแรงและบริการ: เปลี่ยนถ่ายน้ำมันเครื่อง, เช็คระบบไฟ (฿500)"* ช่วยให้ลูกค้าเข้าใจง่าย ไม่รกรุงรัง
- **ความเสถียร 100%:** ตรวจสอบโค้ดทุกจุด ลบ Dead Code และป้องกันปัญหา null/undefined เพื่อให้ระบบทำงานราบรื่นไม่มี Error

## 4. แผนการตรวจสอบและแก้ไข Code Error (Code Audit & Quality Assurance)

1. **ตรวจสอบความสมบูรณ์ของ Type Definitions (`types.ts`):**
   - ตรวจสอบ `LaborServiceItem`, `JobOrder`, `GarageProfile` ให้มีฟิลด์ครบถ้วน ป้องกัน Type Mismatch
2. **คำนวณการเงิน (`financialCalculator.ts`):**
   - รองรับกรณี `laborFee` เป็น 0 หรือค่าว่าง ป้องกัน `NaN`
   - คำนวณส่วนลด, ภาษีมูลค่าเพิ่ม (VAT 7%), ยอดรวมสุทธิอย่างแม่นยำ
3. **การแสดงผลเอกสาร (`PrintDocumentModal.tsx`):**
   - ปรับการเรนเดอร์แถวค่าแรงให้เป็นบรรทัดเดียวตามที่ผู้ใช้งานเลือก พร้อมนำคำอธิบายจาก `laborDescription` หรือรวมชื่อจาก `laborDetails` มาแสดง
4. **ความเข้ากันได้กับการส่งออกและการแจ้งเตือน:**
   - ตรวจสอบ `lineService.ts` ให้ฟอร์แมตข้อความค่าแรงและสถานะถูกต้อง
   - ตรวจสอบ `googleSheetsService.ts` ในการนำเข้า/ส่งออกฟิลด์ค่าแรงและรายละเอียด
5. **การทดสอบ Build & Lint:**
   - รัน `compile_applet` และ `lint_applet` เพื่อยืนยันว่าไม่มี Error ใดๆ หลงเหลือ

## 5. แผนการลงมือปฏิบัติ (Execution Steps)

- **Step 1: อัปเกรด `JobOrderFormModal.tsx`** ให้สลับโหมดยอดรวม/แยกรายการได้คล่องตัว พร้อมปุ่มเลือกค่าบริการมาตรฐานของอู่
- **Step 2: อัปเกรด `JobOrderDetailModal.tsx`** ให้แก้ไขค่าแรงหน้างานได้ทันทีทั้งสองแบบ พร้อมอัปเดตคำอธิบายสรุปงานบริการ
- **Step 3: ปรับแต่ง `PrintDocumentModal.tsx`** ให้แสดงค่าแรงเป็น 1 บรรทัดสรุปชัดเจนพร้อมคำอธิบายงานบริการ
- **Step 4: ตรวจสอบและแก้ไข Code Error ทั้งหมด** ด้วย `compile_applet` และ `lint_applet` ให้ผ่าน 100%
