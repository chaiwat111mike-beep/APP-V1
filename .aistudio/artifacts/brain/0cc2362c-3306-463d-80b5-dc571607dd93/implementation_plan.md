# ระบบบริหารจัดการอู่สงกรานต์ (ช่างไมค์) — Production Web Application Plan

แผนการยกระดับแอปพลิเคชันอู่สงกรานต์ให้เป็นเว็บแอปพลิเคชันสำหรับใช้งานจริงในอู่ซ่อมรถยนต์ได้ทันที ทำงานรวดเร็วบนเว็บเบราว์เซอร์ทุกอุปกรณ์ มีระบบความปลอดภัยด้วยรหัส PIN ด่วนของเจ้าของอู่ พร้อมระบบสำรองและนำเข้าข้อมูลครบวงจรทั้ง JSON และ Excel/CSV

### User Review & Critical Decisions

> [!IMPORTANT]
> **สรุปการตัดสินใจที่ได้รับการยืนยันจากผู้ใช้ (Phase 1 Confirmation):**
> 1. **รูปแบบแอปพลิเคชัน**: ใช้งานผ่านเว็บเบราว์เซอร์ทั่วไปได้อย่างลื่นไหลและรวดเร็วบนมือถือ แท็บเล็ต และคอมพิวเตอร์ โดยไม่จำเป็นต้องติดตั้ง PWA
> 2. **การจัดเก็บข้อมูลและการสำรอง**: ใช้ระบบจัดเก็บข้อมูลในเครื่อง (Offline-First Local Storage) ที่เชื่อถือได้ พร้อมระบบสำรองข้อมูล (Backup) 1 คลิกเป็นไฟล์ JSON และส่งออกรายงานเป็น Excel/CSV
> 3. **ระบบสิทธิ์และความปลอดภัย**: เจ้าของอู่ (ช่างไมค์) เข้าใช้งานระบบได้ทันที โดยมีระบบรหัส PIN ด่วน 4 หลัก (Quick PIN Access) เพื่อล็อกหน้าจอหรือปลดล็อกข้อมูลสำคัญได้อย่างสะดวกรวดเร็ว

---

### 1. Overview & Core Concept

- **What It Does**: ระบบบริหารจัดการงานซ่อมรถยนต์ครบวงจรสำหรับ "อู่สงกรานต์ (ช่างไมค์)" ครอบคลุมการเปิดใบสั่งซ่อม, ติดตามสถานะงานซ่อมในช่องซ่อม (Service Bays), จัดการสต็อกอะไหล่, ทะเบียนลูกค้าและประวัติรถยนต์, การคำนวณเงิน-ส่วนลด-VAT, การออกใบเสนอราคา/ใบเสร็จรับเงิน/ใบส่งมอบรถพิมพ์ลง A4 หรือเซฟเป็น PDF, พร้อมระบบสำรองข้อมูลในเครื่องและระบบล็อกหน้าจอด้วย PIN
- **Target Audience**: ช่างไมค์ (เจ้าของอู่), ช่างประจำอู่, และพนักงานต้อนรับ/แคชเชียร์ ใช้งานผ่านคอมพิวเตอร์หน้าเคาน์เตอร์ แท็บเล็ตตรวจสภาพรถ และมือถือ
- **Key Value**: ใช้งานได้ทันที 100% ไม่พึ่งพาเซิร์ฟเวอร์ภายนอก ข้อมูลไม่สูญหาย สำรองไฟล์เก็บไว้ในเครื่องได้ตลอดเวลา ออกเอกสารงานซ่อมคมชัดระดับมาตรฐานสากล

### 2. User Experience & Visual Design

- **Key User Flows**:
  1. **Quick Unlock & Direct Dashboard**: เปิดหน้าเว็บมาจะเข้าสู่หน้าจัดการอู่ได้ทันที โดยมีปุ่ม "ล็อกหน้าจอ (PIN Lock)" ที่มุมขวาบน เมื่อต้องผละออกจากหน้าจอ สามารถกดล็อก และปลดล็อกด้วย PIN 4 หลักได้อย่างรวดเร็ว
  2. **End-to-End Repair Workflow**: รับรถใหม่ -> บันทึกอาการและรูปรถ -> มอบหมายช่างและช่องซ่อม -> เบิกอะไหล่และบันทึกค่าแรง -> ออกใบเสนอราคา/ใบรับรถ -> ตรวจเช็คสภาพ -> สรุปเงิน หักมัดจำ คิดส่วนลด/VAT -> รับชำระเงินผ่าน PromptPay QR -> พิมพ์ใบเสร็จ/ส่งสรุปเข้า LINE
  3. **Data Protection & Backup Center**: เมนู "สำรองและกู้คืนข้อมูล" ในแถบตั้งค่า ให้เจ้าของอู่กดปุ่ม "📥 ดาวน์โหลดไฟล์สำรองข้อมูล (JSON Backup)" หรือ "📊 ส่งออกข้อมูลเป็น Excel (.xlsx / .csv)" ได้ในคลิกเดียว พร้อมปุ่ม "📤 กู้คืนข้อมูลจากไฟล์" เมื่อต้องการย้ายเครื่องหรือกู้ข้อมูลเก่า
- **Visual Identity & Theme**:
  - *Aesthetic*: Modern Utilitarian Automotive Workshop Dashboard — ธีมสีดำเข้มดุดันตัดทองคำแอมเบอร์ (Dark Charcoal `#0F1113`, Slate `#16191D`, Accent Gold `#F59E0B` & Racing Yellow `#EAB308`)
  - *Typography*: ฟอนต์ภาษาไทยและอังกฤษสไตล์ Prompt / Plus Jakarta Sans คมชัด อ่านง่าย ตัวเลขทั้งหมดใช้ `tabular-nums` เพื่อจัดตำแหน่งหลักเงินและสต็อกตรงกันอย่างเป็นระเบียบ
  - *Print/PDF Mode*: หน้าเอกสาร A4 สีขาวบริสุทธิ์ ตัวหนังสือสีดำสนิท `#000000` เส้นขอบคมชัด สแกน QR และพิมพ์ออกมาได้ชัดเจน 100%

### 3. Key Product Decisions & Trade-Offs

- **Decision 1: Storage & Data Engine Architecture**:
  - *Chosen Approach*: Robust LocalStorage + Memory Cache พร้อมระบบ Data Backup / Restore (JSON Snapshot + CSV/Excel Export)
  - *Why*: ตอบโจทย์การใช้งานจริงในอู่ได้ทันทีโดยไม่ต้องตั้งค่า Cloud หรือกังวลเรื่องอินเทอร์เน็ตหลุด ทำงานได้รวดเร็วระดับเสี้ยววินาที และเจ้าของอู่สามารถถือไฟล์สำรองข้อมูลไว้กับตัวได้อย่างปลอดภัย
- **Decision 2: Quick PIN Security & Owner Authentication**:
  - *Chosen Approach*: เจ้าของอู่กำหนดรหัส PIN 4 หลักได้เองในหน้าการตั้งค่า (ค่าเริ่มต้น เช่น `1111` หรือเปลี่ยนได้ตามใจชอบ) พร้อมระบบ Session Lockout เพื่อความปลอดภัยเมื่อทิ้งหน้าจอไว้ที่อู่
  - *Why*: สะดวกและเร็วกว่าการล็อกอินด้วยอีเมล/รหัสผ่านยาวๆ สำหรับหน้างานในอู่ซ่อมรถ

- **Core Module Roadmap**:
  1. **Quick PIN Lock & Owner Access Guard**: เพิ่มวิดเจ็ต PIN Lock ที่แถบส่วนหัว พร้อมหน้าต่างใส่รหัส PIN 4 หลัก (ตั้งค่า PIN ได้ใน Settings) เพื่อความปลอดภัยเมื่อใช้งานในอู่
  2. **Backup & Restore Hub**: เพิ่มฟังก์ชันการสำรองข้อมูล (Full Backup JSON) และการกู้คืนข้อมูล (Restore Backup) รวมถึงการส่งออกข้อมูล (Export CSV/Excel) สำหรับใบสั่งซ่อมและอะไหล่
  3. **Production Polish & Offline Readiness**: ปรับแต่งความเสถียร ตรวจสอบระบบแคชในเบราว์เซอร์ และปรับปรุงข้อความ/ปุ่มกดทุกจุดให้กระชับ ชัดเจน ใช้งานง่ายในหน้างานจริง
